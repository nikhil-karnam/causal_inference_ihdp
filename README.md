an implementation and evaluation of two CATE estimators — dragonnet (a multi-task neural network, PyTorch) and an x-learner with cross-fitting (scikit-learn) — benchmarked on the semi-synthetic ihdp dataset. targeted regularization reduced dragonnet's PEHE by 10.5% over the base model, and both models beat a naive baseline. treatment effect heterogeneity was analyzed using the BLP / GATES / CLAN framework from Chernozhukov et al., pooled across 100 replications using monte carlo approximation and wilcoxon signed-rank test.

in causal inference, treatment effect is defined as an individual's potential outcome when treated ($Y_1$) minus the potential outcome when untreated ($Y_0$). ATE (average treatment effect) is $Y_1 - Y_0$ averaged across all individuals. and CATE (conditional average treatment effect) is averaged across those who non-negotiably share a certain trait value or exact set of trait values.

the ihdp dataset comes from an randomized controlled experiment in the 1980s. jennifer hill later turned this dataset into synthetic observational data to help study causal machine learning. she did this by artificially introducing a confounder: removing non-white mothers in the treated group. when confounding exists, a naive difference in average treatment effect across groups will produce a biased result. here, the treated group being white is associated with socioeconomic advantages that affect the outcome variable in the study. thus the outcome variable is artificially inflated. the goal of CATE estimators in causal machine learning is to say "instead of a biased naive difference in average outcome, let's compare the outcome for individuals that share the same level of confounders, in an attempt to eliminate the effect of the confounders." controlling for confounders is what allows inferring causality to be more legal. hence, the name.

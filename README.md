An implementation and evaluation of a T-learner (a CATE estimator) to estimate treatment effects in the IHDP dataset with 25 effect-distorting participant traits, reporting error with PEHE. Achieved 50.6% lower error than a bias-ignoring model (p<.001) across 100 Monte Carlo replications. Cut model training time 16x via 24-core parallelized training. Heterogeneity in treatment effect (HTE) was analyzed using the BLP / GATES / CLAN framework from Chernozhukov et al. Histograms demonstrate skewed distributions across reps, justifying analysis on the median. Uplift curves visualize cumulative gain in outcome as the participants with the highest predicted response are treated first.

Background:
In causal inference, treatment effect is defined as an individual's potential outcome when treated ($Y_1$) minus the potential outcome when untreated ($Y_0$). ATE (average treatment effect) is $Y_1 - Y_0$ averaged across all individuals. And CATE (conditional average treatment effect) is averaged across those who non-negotiably share a certain trait value or exact set of trait values.

The IHDP dataset comes from an randomized controlled experiment in the 1980s. The dataset was later turned into synthetic observational data to help study causal machine learning. This was done by artificially introducing a confounder: removing non-white mothers in the treated group. Because the treated group is white only, and due to circumstances a few decades ago, the group is associated with socioeconomic advantages that raise the pre-treatment baseline outcome and thus, the post-treatment outcome in the study. This makes a raw difference in mean outcomes between the treated and control groups be an inflated treatment effect estimate. CATE estimators instead say, "let's compare each individual with themselves". The T-learner uses training data and fits a model that predicts the outcome given the treatment and the outcome without the treatment, using covariates. This is applied to the test data to compute CATE estimates. Controlling for confounders is what allows inferring causality to be more legal. Hence, the name causal inference.
